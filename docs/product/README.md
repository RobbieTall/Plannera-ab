# Product Documentation

Canonical product-level capability and output standards live in this directory.

- [Plannera SEE Builder — World-Class Flexible Standard](see-builder-standard.md) — approval-oriented, evidence-led, development-specific SEE architecture and drafting standard.
- [Practitioner Workflow Intelligence and Source Governance](practitioner-workflow-intelligence.md) — defines how real practitioner workflows may improve Plannera without being mistaken for statutory authority or a universal planner methodology.
- [Evidence-aware concept design and CAD handoff](evidence-aware-concept-design.md) — future concept geometry, evidence provenance and CAD handoff capability contract.

The SEE Builder standard should be treated as the primary document-generation contract for future SEE architecture, prompting, section selection, specialist-report integration, quality gates and professional output acceptance.

Practitioner workflow material may influence what Plannera investigates and how it structures an assessment, but authoritative current sources remain determinative of what Plannera states. Real-user pilots are validation inputs, not automatic planning precedents.
