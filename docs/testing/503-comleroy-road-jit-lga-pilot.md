# Live User Pilot — 503 Comleroy Road, Kurrajong

Status: Candidate unsupported-LGA real-user pilot; not yet a validated golden case  
User: Mick  
Last updated: September 2026

## Purpose

Use this project to test Plannera's existing Just-in-Time LGA Activation architecture with a genuine user and genuine project evidence outside the established Byron/Kempsey pilot coverage.

## Current evidence

Drive currently contains a detailed survey PDF, corresponding DWG and four drone/site photographs.

## Acceptance focus

The pilot should test:

- canonical address/LGA resolution;
- detection of insufficient local-control maturity;
- useful immediate state/LEP baseline where authoritative evidence is available;
- truthful queued/in-progress/ready/failed local preparation state;
- council DCP/mapping/local-policy discovery and source registration;
- provenance, freshness and authority checks;
- zone-aware retrieval and structured-control extraction;
- duplicate-job prevention and shared LGA preparation;
- persistent completion notification;
- regeneration of the exact same project after local evidence improves;
- survey/DWG/image evidence provenance;
- fail-closed handling of missing, stale, conflicting or unsupported evidence;
- maturity promotion only after source and golden-case QA.

## Boundary

Do not manually complete the planning answer and then treat that as evidence that the LGA is supported. The product value under test is the activation process itself: baseline intelligence immediately, visible limitations, local preparation, validation and progressively stronger outputs on the same project.

The case is not a planning precedent or golden regression case until expected outcomes are independently validated.

## Success signal

A real user can start an unsupported-LGA project, receive an honest useful baseline, see local intelligence being prepared, return to the same project, and receive stronger cited outputs without duplicate project scope, hidden manual reconstruction or false claims of coverage completeness.
